# 资料语义与接口边界

查询为一个或多个非空关系原子的自然inner join，各列绑定变量名，原子可以重复引用变量；最终投影所有逻辑变量，每个输出附精确multiplicity，不要求重复输出同一值行。值类型为int或string，单变量类型一致，null永不等值；逻辑变量按类型全序。relations.py提供冻结的PrefixRelation，可对指定列排列建前缀视图并next_values(prefix)、seek(prefix,lower)、count_exact(tuple)；该基础接口会记录实际访问量但不实现多路连接。原子列排列必须与所选全局变量顺序一致，重复变量先做一致性筛选。计划绑定关系digest和变量绑定，过期视图不能读取。不能物化未满足全部原子的二元笛卡尔中间关系；允许原子自身的索引与输出分批。

relations.py可创建列排列、探查前缀并计算原子内计数，未提供多个原子的联合执行器。当前实现用于固定小关系访问，调用日志可见。

正文摘要绑定完整值，样例数据不限定输入规模；错误不等同空结果，接口使用中文错误说明。
